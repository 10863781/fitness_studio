# Milano Fitness Studio

Fitness studio site: a React + Tailwind frontend with a Node.js + Express backend.

## Folder structure

```
client/   React + Vite + Tailwind frontend (what the visitor sees)
server/   Express API (talks to the database, handles login)
```

## Run locally

Open two terminals:

```bash
# terminal 1 – the API on http://localhost:3000
cd server
npm install
npm run dev

# terminal 2 – the website on http://localhost:5173
cd client
npm install
npm run dev
```
